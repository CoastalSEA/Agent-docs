# prompts

Prompt and workflow templates that are not tied to one tool.

- `blank-prompt-template.md`: the guide to writing a prompt for one task. Copy it and fill it in. The two templates below follow its sections.
- `delegation-map.md`: a short triage for deciding how much of a task to delegate. From the Agent workflows course repository.
- `literature-synthesis-template.md`: reasons over a `literature-search` run to build a theoretical account, identify agreement and disagreement, and name gaps.
- `reanalysis-triage-template.md`: reads an `analysis-adversary` report against its source report and recommends, per finding, whether reanalysis, a caveat or further investigation is warranted.
- `new-skill-workflow.md`: the three-phase process (rough draft, refine against real data, deploy and validate) used to build every skill in `skills/`. Read it before starting a new skill.

The two templates are prompts, not skills, because the step is open reasoning over a varying body of evidence and not a fixed checklist.
