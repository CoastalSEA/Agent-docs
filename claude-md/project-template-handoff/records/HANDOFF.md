# Handoff

This file lives at `records/HANDOFF.md` in the project root. Overwrite it each time. Write it at a checkpoint (a unit of work closes, or before a push), before compacting or stopping, or when the user says "checkpoint" or "wrap up". Keep it to 3,000 characters or less. This file holds only the state at the end of the session. Anything that must outlast the next handoff (a decision, a data problem, a source) goes in a memory note.
