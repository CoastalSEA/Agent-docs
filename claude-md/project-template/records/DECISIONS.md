# Decisions

This file lives at `records/DECISIONS.md` in the project root. One line per decision, newest last. Add a line whenever a decision is made, before the session ends. The evidence file is the output, script or document that supports the decision. A decision that is later reversed stays in the list, with a new line that says so and points to the old one.
