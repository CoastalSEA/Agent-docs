# Decisions

This file lives at `records/DECISIONS.md` in the project root. One line per decision, newest last. Add a line when a decision is made. Keep a line to about 500 characters and the file to 100 rows: the script rotate_records.py moves the oldest rows to records/DECISIONS-archive.md, which is searched as well. The evidence file is the output, script or document that supports the decision. A decision that is later reversed stays in the list, with a new line that says so and points to the old one.
