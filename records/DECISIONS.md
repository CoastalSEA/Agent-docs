# Decisions

This file lives at `records/DECISIONS.md` in the project root. One line per decision, newest last. Add a line whenever a decision is made, before the session ends. Git holds what changed and why in each commit. This file holds the decisions that a commit message does not carry, such as a choice not to do something. Evidence is a path in this repository or a commit hash (`git show <hash>`). Do not record user quotes or session-log citations here.
